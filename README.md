<h2> Descripción:</h2>
<p>Aplicación de consola desarrollada en C# que permite calcular el área de un triángulo, un cuadrado y un círculo, además de evaluar si una persona es mayor o menor de edad mediante métodos dedicados invocados desde el programa principal dentro de un menú interactivo.</p>

<h2>Datos de Entrada:</h2>

<p>Base y altura del triángulo.<br>
  
Lado del cuadrado.<br>

Radio del círculo.<br>

Edad de la persona.</p>  

<h2>Datos que Procesa:</h2>

<p>Cálculo de área de triángulo mediante la fórmula `(base * altura) / 2.0`.<br> 
  
 Cálculo de área de cuadrado mediante lado * lado.<br>
 
 Cálculo de área de círculo mediante Math.PI * radio * radio.<br>
  
 Evaluación de edad para verificar si es mayor o menor de edad. </p>

<h2>Datos de Salida:</h2>

<p>Resultado del área del triángulo, del cuadrado y del círculo mostrados en consola con dos decimales.<br>
  
Mensaje indicando si la persona es mayor o menor de edad según el valor ingresado.</p>
